【開発指示書】ターゲット年齢×固有名詞連携 キャラクター自動生成＆マトリクス管理システム1. システム概要と目的本システムは、ユーザーが指定した「ターゲット年齢（年齢ウェイト）」と「固有名詞（原案モチーフ）」を入力パラメータとし、1〜6歳児向けデザイン理論（6大ベクトル×XYZ軸マトリクス）に基づいて、キャラクター設定・世界観・AI生成プロンプト（メイン画像/3面図）をブレなく自動生成するエンジンである。2. システム入出力仕様（Input / Output）【入力（Input）】JSON{
  "target_age": 2.5,          // 1.0 〜 6.0（歳数。小数の入力も可）
  "proper_noun": "ドーナツ",  // モチーフとなる固有名詞（名詞、単語）
  "render_style": "2D_Flat"   // "2D_Flat" または "3D_Clay" （Z軸指定。オプション）
}

- X_weight = (target_age - 1) / 5 * 100
- X <= 30: 【1-2歳モード】1.2頭身, 超太線, 2-3色, 顔パーツ低い位置, 点目, オノマトペ名, もちもち抽象質感

- X > 70: 【5-6歳モード】2.5頭身, 中太線, 4-5色, 役割・衣装・決めポーズ, ヒーロー/キャプテン名
